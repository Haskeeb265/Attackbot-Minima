# =============================================================================
# generic.txt - built-in DNS bruteforce wordlist (single labels)
# =============================================================================
# One label per line; `#` starts a comment; blank lines ignored.  Every entry
# must be a single DNS label (letters, digits, hyphen) - the loader rejects
# anything with a dot, because a dotted entry is a hostname, not a word.
#
# This is a SEED list, not an attempt to beat SecLists.  It is deliberately
# small enough to run against any target in well under a minute while carrying
# the labels that actually resolve again and again in practice: environments,
# internal services, admin surfaces, CI/CD, observability, and the usual
# cloud/legacy leftovers.
#
# For deeper coverage point --wordlist at a larger list, e.g.:
#   SecLists  Discovery/DNS/subdomains-top1million-5000.txt   (5k, fast)
#   SecLists  Discovery/DNS/subdomains-top1million-110000.txt (110k, thorough)
#   Assetnote wordlists.assetnote.io  best-dns-wordlist.txt   (very large)
# Layering works too: --wordlist can be repeated, and the built-in list is
# always included unless --no-builtin-wordlist is passed.
#
# Keep entries sorted within a section and lowercase.
# =============================================================================
