# =============================================================================
# Trusted resolver candidates (seed list)
# =============================================================================
# Used for puredns' *poisoning validation* pass (`--resolvers-trusted`): after a
# fast pass over the big public pool, every surviving name is re-queried here,
# and only names these resolvers also confirm are kept.  That pass is what stops
# a hijacking or lying resolver in the public pool from planting fake hosts.
#
# Two rules for membership, both stricter than public.txt:
#
#   1. UNFILTERED ONLY.  A resolver that blocks domains (AdGuard, CleanBrowsing,
#      Cloudflare's 1.1.1.2/1.1.1.3 malware sets, Quad9's filtered 9.9.9.9) can
#      return NXDOMAIN for a name that genuinely exists.  Here that would
#      *delete a real host*, so filtering resolvers are excluded - which is why
#      this list is not simply "the first N entries of public.txt".
#   2. INDEPENDENT OPERATORS.  Multiple addresses from one operator share
#      infrastructure and failure modes, so the value is in operator diversity
#      (Cloudflare + Google + Quad9 unfiltered), not address count.
#
# Every entry is still probed at run time (positive + `.invalid` negative), so a
# provider that dies simply drops out of the validated pool with a reason.
#
# Format: one IPv4 address per line; `#` starts a comment; blank lines ignored.
# Validated output is written to active/output/resolvers-trusted.txt.
# =============================================================================
